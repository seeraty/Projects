# Projects
Author: Seerat Yasir. [LinkedIn](https://www.linkedin.com/in/seerat-yasir-811878298/)

A collection of projects developed during my studies at KTH Royal Institute of Technology and personally.

* To-Do List Application: My first programming project; a command-line _to-do list_ application developed in Java as part of a programming project course. Developed in collaboration with Ava Vatanchi.
* Ping-Pong: Developed a Ping-Pong game on an Arduino using MIPS assembly and C as part of a Computer Organization and Architecture course. Developed in collaboration with Chloe Joyce Raneses.
* Weakest link: Created a command-line version of the popular game show _The Weakest Link_ for a game night event that I hosted. Implemented in Java in ~15 minutes.
* Rebuilding MSKTH's website ([website repo](https://github.com/mskth-webpage/mskth)): Collaborated with a team to rebuild a student organisation's website from scratch using Next.js, TypeScript, Tailwind CSS and Supabase. Primarily responsible for developing the board members section, including its public-facing page and administrative interface. Also contributed reusable components, sections and functionality across the website, working full stack.  
My contributions included:
    * Contributing to requirements and UI feedback (as I was a boardmember).
    * Designing and implementing frontend views, presenters, reusable components and modals.
    * Developing database tables, types and access permissions in Supabase.
    * Implementing data-fetching, updating and deleting functionality to retrieve and manage board member information.
    * Building an editing workflow that saves unpublished changes to local storage, allowing administrators to review and modify changes before publishing them to the database.
    * Implementing input validation, error handling and user feedback to ensure data consistency.
 
Other notable projects:

Worked with Figma, WordPress and contributed to custom functionality and website development using PHP and CSS. As project lead, I coordinated the team's work and helped drive the project from planning to implementation.
